SECUENCIA TÉCNICA DE REINICIO DE MÓDEM / ROUTER

Se ejecutará el envío del paquete de reinicio HTTP/API al Gateway local (192.168.1.1), forzando el reseteo del enlace WAN y la renegociación de la tabla de rutas.

1. Solicitud POST /api/reboot-router enviada a Gateway local
2. Desconexión del adaptador de interfaz (`ipconfig /release`)
3. Purgado de registros de resolvedor DNS local (`ipconfig /flushdns`)
4. Negociación y reasignación de dirección IP vía DHCP (`ipconfig /renew`)
5. Verificación de RTT ICMP y sincronización con Relay Valve
ESTADO DEL PROCESO 0%
BACKEND LOCAL EN PYTHON / FASTAPI (HOOK DE REINICIO REAL)

Para vincular el botón de reinicio con tu adaptador físico o router de red local, puedes ejecutar este microservicio local en Python que atiende peticiones HTTP en el puerto 8000: 

# orion_dota_backend.py
# Dependencias: pip install fastapi uvicorn requests
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import subprocess

app = FastAPI(title="Orion Dota NetControl Local Service")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.post("/api/reboot-router")
def reboot_network():
    # 1. Purgado de memoria DNS local
    subprocess.run("ipconfig /flushdns", shell=True)
    # 2. Reinicio de adaptador de interfaz de red (Windows)
    subprocess.run("netsh interface set interface 'Wi-Fi' disable", shell=True)
    subprocess.run("netsh interface set interface 'Wi-Fi' enable", stroke=True)
    return {"status": "SUCCESS", "message": "Interfaz y DNS reiniciados con exito"}

# Ejecución: uvicorn orion_dota_backend:app --port 8000
Endpoint objetivo: http://localhost:8000/api/reboot-router
